# Calculator

A simple calculator built with **HTML, CSS, and JavaScript** as part of [The Odin Project](https://www.theodinproject.com/) curriculum.  

This project focuses on DOM manipulation, event handling, and implementing basic arithmetic operations with operator chaining (e.g., `12 + 7 - 1 = 18`).

---

## 🚀 Features
- Perform basic arithmetic: addition, subtraction, multiplication, and division.
- Chain operations together without pressing `=` each time.  
  Example: `12 + 7 - 1` → evaluates step by step → result `18`.
- Handles division by zero (`Error` shown).
- Clear button (`C`) resets the calculator.
- Responsive grid layout for calculator buttons.
